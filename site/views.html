Views: what disagreement is “really about”

This page lists every account of what a disagreement is really about. Use it when you want a diagnosis: where a dispute lives, and so what would end it, contain it or honour it.

How this bears on the thesis: each view lists the methods that assume it, so you can see which diagnoses have a method and which do not. The thesis

Some diagnoses in this survey have no method built on them. Each says what disagreement is really about, and no method in the survey takes it as a premise. Some gaps belong to the survey, and each card names the nearest existing practice where one is known. For each view the page then sketches what a method might look like. The sketches are this site’s own proposals, untested, and each is labelled as one.
