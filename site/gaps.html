What no one has built

Gap gallery

Thirteen diagnoses in this survey have no method built on them. Each says what disagreement is really about, and no method among the seventy takes it as a premise. Some gaps belong to the survey, and each card names the nearest existing practice where one is known. For each view the page then sketches what a method might look like. The sketches are this site’s own proposals, untested, and each is labelled as one.
